
# **CEH Engage – Parte I**

### *(Footprinting, Reconnaissance, Scanning, Enumeration, Vulnerability Analysis)*

### **Desafios**

**Desafio 1**
Um atacante realizou footprinting em uma aplicação web e salvou o relatório `Dumpster.xlsx`. Analise o relatório e identifique o **hostname associado ao IP 173.245.59.176**.
(Formato: `aaaaa.aa.aaaaaaaaaa.aaa`)

**Desafio 2**
Identifique o **número de máquinas ativas**, excluindo o gateway, na sub-rede `192.168.10.0/24`.
(Formato: `N`)

**Desafio 3**
Identifique o **IP de uma máquina Linux** com a **porta 22 aberta** na rede `192.168.10.0/24`.
(Formato: `NNN.NNN.NN.NNN`)

**Desafio 4**
Encontre o **IP do Domain Controller** na sub-rede `192.168.0.0/24`.
(Formato: `NNN.NNN.N.NNN`)

**Desafio 5**
Realize host discovery e identifique o **NetBIOS Domain Name** do host `192.168.0.222`.
(Formato: `AAAAA.AAA`)

**Desafio 6**
Execute um **intense scan** no host `192.168.0.222` e encontre o **DNS Tree Name**.
(Formato: `AAAAA.AAA.aaa`)

**Desafio 7**
Uma máquina executa **OpenSSH vulnerável** na rede `192.168.10.0/24`. Identifique a versão.
(Formato: `N.NaN`)

**Desafio 8**
Um servidor hospeda um site vulnerável a **Blind SQL Injection** com banco **MySQL**. Determine o **sistema operacional da máquina**.
(Formato: `Aaaaaa`)

**Desafio 9**
Identifique o **IP da máquina que hospeda o serviço MSSQL**.
(Formato: `NNN.NNN.NN.NNN`)

**Desafio 10**
Realize enumeração DNS em `www.certifiedhacker.com` e identifique os **name servers**.
(Formato: `aaN.aaaaaaaa.aaa, aaN.aaaaaaaa.aaa`)

**Desafio 11**
Identifique o **IP do servidor SMTP** na rede `172.30.10.0/24`.
(Formato: `NNN.NN.NN.NNN`)

**Desafio 12**
Enumere SMB no host `172.30.10.200` e verifique se **Message Signing é obrigatório**.
(Resposta: `Yes` ou `No`)

**Desafio 13**
Identifique o nome associado à **CWE ID 276**.
(Formato: `Aaaaaaaaa Aaaaaaa Aaaaaaaaaaa`)

**Desafio 14**
Utilize o OpenVAS e determine o **QoD (%)** de vulnerabilidade média.
(Formato: `NN`)

**Desafio 15**
Identifique uma **vulnerabilidade relacionada a FTP** no host `192.168.10.144`.
(Formato: `AAA Aaaaaaaaa Aaaaaaaaa Aaaaa`)
